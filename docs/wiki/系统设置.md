# 系统设置

面板 **系统设置** 聚合运营向配置（多数存数据库，不必改 `config.yaml`）。

## 语言与主题

界面中英文切换、主题相关选项。

## Telegram

见 [[Telegram-Bot]]。

## 订阅页模板

- 主题目录、页面标题、支持链接
- 公告、Profile 网页 URL
- 刷新间隔（小时）
- 是否 Base64 编码 URI 列表
- 下载默认 HTML 模板

见 [[订阅]]。

## GeoIP / GeoSite

一键下载 MetaCubeX 数据库到 Mihomo 数据目录，供路由规则使用。

## 流量重置

可配置每月重置日等策略（若版本已启用对应开关）。

## 模板

TLS / 反代配置片段生成，便于复制到 Nginx、Caddy 等。
